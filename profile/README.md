## Fast Xbox Home Streaming Brief

What is Greenlight? An independent, open-source client for Xbox home streaming and Xbox Cloud Gaming.  
Why use it for Xbox Home Streaming? It puts the picture and sound from your own Xbox on a Windows PC and sends controls back.  
Who needs it? Xbox owners who want to use a desk display or play while the main TV is busy.  
Does it support Xbox Series X and Series S? Yes, the project lists Xbox Series consoles as supported home-streaming hosts.  

## Xbox Home Streaming Overview

Greenlight gives you a Windows window for the video and audio coming from your Xbox. The console runs the game and the app relays your controller input. This independent guide covers that home-console workflow, not a native Windows installation of GTA VI.

Home streaming starts from an Xbox you have configured for remote access. Cloud streaming instead starts a session on Microsoft's service, where title availability, regions and account eligibility are separate concerns. Test the home-console path first rather than using the cloud catalog to diagnose a missing console.

Greenlight is not affiliated with Microsoft or Xbox. Reviews are most useful when they say which mode, release and network they tested. For alternatives, compare the first-party Xbox Remote Play route for console access and the cloud route for cloud play.

## Getting Started Playbook

On Xbox, open Settings → Devices & connections → Remote features and enable remote features. Run the console's remote play test and test your first Greenlight session while the console is awake. Where possible, wire the console to the router and keep the PC on the same network.

Install the Windows build from the Greenlight project and connect your gamepad to the PC. Sign in with the Microsoft account associated with the console and select your Xbox from the console list, not a title from the cloud catalog. Verify navigation and audio, then test whether the Xbox's configured power mode permits remote wake.

## Everyday Use

Open the app and confirm the login matches the profile linked to your Xbox before selecting the console. Start with the gamepad connected so you can verify the controls in the dashboard. Features such as the debug overlay can help you spot decoder lag or a growing buffer when a session feels sluggish. The project documents the tilde key for toggling statistics during a stream.

## Practical Scenarios

Scenario A - Shared screen: Connect from a Windows PC while the living room display is showing another source.  
Scenario B - Controller test: Compare dashboard navigation over a wired USB gamepad connection before troubleshooting wireless input.  
Scenario C - Missing Xbox: Wake the console and verify the Microsoft account and Remote features setting before trying again.  
Scenario D - Cloud confusion: Select the home console list if your goal is to play something installed on your own Xbox.

## Troubleshooting Common Issues

Install issues? Choose a Windows build from the project Releases page rather than the source-code archive.  
Performance problems? Pause heavy traffic and check the in-stream buffer and decoder statistics over a wired connection.  
Edition differences? There is no Greenlight unlock key; check the Microsoft sign-in for home streaming separately from cloud play eligibility.
Compatibility? Verify the Xbox model, Remote features setting and gamepad input on Windows before blaming the client.  
Update failures? Check the release notes and use a clean copy of the correct Windows build instead of merging files from different versions.
